API Reference Documentation

Authentication Headers

Authenticate request frames by passing keys inside Bearer headers.

Authorization: Bearer YOUR_API_KEY
POST /v1/text-to-speech

Synthesizes raw script text strings into neural MP3/WAV waveforms stream buffers.

GET /v1/voices

Retrieves metadata profiles representing available synthetic actors.

GET /v1/user

Returns account quota status details and active project totals.

Code Snippet Examples

fetch('https://api.voicenova.ai/v1/text-to-speech', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer ',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    text: "Synthesize voice.",
    voice: "Nova"
  })
})
import requests

res = requests.post(
  'https://api.voicenova.ai/v1/text-to-speech',
  headers={'Authorization': 'Bearer '},
  json={'text': "Synthesize.", 'voice': "Nova"}
)
const axios = require('axios');

axios.post('https://api.voicenova.ai/v1/text-to-speech', {
  text: "Synthesize voice.",
  voice: "Nova"
}, {
  headers: { 'Authorization': 'Bearer ' }
})
